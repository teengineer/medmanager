# PWA icons

Drop your generated PNGs here:

- `icon-192.png` — 192×192
- `icon-512.png` — 512×512
- `icon-maskable-512.png` — 512×512, with safe zone for maskable rendering

Use [maskable.app](https://maskable.app/) or [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator) to produce them from a master 1024×1024 SVG.
